# 蓝牙声音功能排查指南

## 如果听不到声音，请按以下步骤检查：

### 1. 检查声音开关是否开启

#### 方法一：通过设置页面
1. 打开应用
2. 进入"功能列表"标签页
3. 点击"设置"
4. 找到"蓝牙接收声音"选项
5. **确保开关已打开**（显示为蓝色）
6. 应该看到提示："已开启蓝牙接收声音"

#### 方法二：查看控制台日志
运行应用时，在控制台查找以下日志：
```
[蓝牙] ========== 声音设置加载 ==========
[蓝牙] 声音开关状态: true
[蓝牙] ✓ 声音已开启，接收数据时将播放提示音
[蓝牙] ====================================
```

如果显示 `false`，说明声音未开启。

---

### 2. 检查是否正在接收数据

在蓝牙页面：
1. 连接蓝牙设备
2. 点击"同步"按钮
3. 观察是否有新数据接收

控制台应该显示：
```
[蓝牙] 播放提示音，音量: 0.8, 连续次数: 1
```

或者：
```
[蓝牙] ✓ 播放在线提示音成功，音量: 0.8
```

---

### 3. 检查控制台日志

运行应用并连接到设备后，查看控制台输出：

#### 情况A：看到 "声音未开启，跳过播放"
**原因**: 声音开关未打开  
**解决**: 去设置页面开启"蓝牙接收声音"

#### 情况B：看到 "声音间隔太短，跳过 (XXXms)"
**原因**: 数据接收太快，触发了间隔保护  
**解决**: 这是正常现象，等待一下就会有声音

#### 情况C：看到 "本地音频文件不存在"
**原因**: 没有本地的 notification.mp3 文件  
**解决**: 系统会自动尝试在线提示音，这是正常的

#### 情况D：看到 "在线提示音也失败"
**原因**: 网络连接问题或Google音效服务不可用  
**解决**: 
- 检查网络连接
- 或者添加本地音频文件（见下文）

#### 情况E：没有任何日志
**原因**: 可能没有接收到数据  
**解决**: 确认蓝牙设备已连接并正在同步

---

### 4. 添加本地音频文件（推荐）

在线提示音依赖网络，建议添加本地音频文件：

#### 步骤：
1. 下载一个简短的提示音文件（MP3格式，0.1-0.5秒）
   - 可以从在线音效网站下载
   - 或使用音频编辑软件制作

2. 将文件重命名为 `notification.mp3`

3. 放到项目目录：
   ```
   /Users/pan3dme/Desktop/oframe2025/flutter/001/assets/sounds/notification.mp3
   ```

4. 重新运行应用

#### 推荐的音效类型：
- 短促的"滴"声
- 清脆的提示音
- 避免过于刺耳的声音

---

### 5. 检查设备音量

确保：
1. 手机/平板的媒体音量已打开
2. 不是静音模式
3. 音量不要调得太低

**iOS**: 从屏幕右上角下滑，检查音量滑块  
**Android**: 按音量+键，确保媒体音量已开启

---

### 6. 测试音频播放器

在蓝牙页面的控制台，如果你看到：
```
[蓝牙] ✓ 播放本地提示音成功
```
或
```
[蓝牙] ✓ 播放在线提示音成功
```

但依然听不到声音，可能是：
- 设备音量为0
- 设备处于静音模式
- 蓝牙耳机未连接或音量过低

---

### 7. 常见问题

#### Q: 为什么有时候有声音，有时候没有？
A: 因为有500ms的最小间隔保护。如果数据接收太快，会跳过部分声音以避免干扰。

#### Q: 声音太小怎么办？
A: 系统会根据连续接收次数自动调整音量：
- 1-3次：80%音量
- 4-5次：90%音量
- 6次以上：100%音量

你也可以调大设备音量。

#### Q: 可以自定义提示音吗？
A: 可以！在 `assets/sounds/notification.mp3` 放置你喜欢的提示音文件即可。

#### Q: 为什么启动时没有声音？
A: 只有在蓝牙页面接收到数据时才会播放声音。需要：
1. 开启声音开关
2. 连接蓝牙设备
3. 开始同步
4. 接收到数据

2. 是否看到"声音开关状态: true"
